# SRS Summary

The Software Requirements Specification (SRS) for ZK-Stables defines the full set of functional and non-functional requirements for the USDC/USDT non-custodial bridge. It covers the bridge's operational requirements across all three target chains (EVM, Cardano, Midnight), specifying lock/mint and burn/unlock flows, relayer behavior, proof verification, finality thresholds, access control, and the strict-mode (`RELAYER_SRS_STRICT`) enforcement model that validates all required environment variables and chain integrations at startup.
