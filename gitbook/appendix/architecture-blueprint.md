# Architecture Blueprint

The Architecture Blueprint provides the system-level design for the ZK-Stables non-custodial bridge, detailing the component topology, data flow, and interaction patterns between the EVM pool contracts, Cardano Aiken validators, Midnight Compact programs, and the relayer orchestration layer. It covers the end-to-end control flow from lock ingestion through finality verification, proof generation, and destination settlement, along with the concurrency model, wallet management strategy, and deployment architecture for the three-chain bridge infrastructure.
